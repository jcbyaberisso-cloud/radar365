# Radar 365

Radar autónomo de oportunidades de fútbol orientado a comparar probabilidad estimada, cuota justa y cuota disponible.

## Objetivo

- Analizar partidos automáticamente.
- Priorizar pocas oportunidades de alta calidad.
- Mercados: remates, remates al arco, atajadas, goles, goles de equipo, corners, tarjetas, handicaps, BTTS, goles/asistencias y combinaciones sensatas.
- Incorporar XI probable/oficial, bajas, suspensiones, rotación, descanso, contexto competitivo, localía, forma reciente y fuerza del rival.
- No inventar cuotas: cuando no exista una cuota Bet365 verificable, mostrar la cuota mínima necesaria para que exista valor.
- Registrar cada señal para backtesting y calibración.

## Estado

Repositorio inicializado. Próximo bloque: aplicación web/PWA + motor de valor + conectores de datos + persistencia + ejecución programada.

> Radar 365 es una herramienta de análisis. No inicia sesión ni ejecuta apuestas en nombre del usuario.
